Contexto de Gestión del Sistema

Sistema de inventario para depósito comercial basado en Arreglo de Estructuras (AoS). Implemente los módulos de gestión algorítmica sobre el catálogo de artículos y resuelva la traza manual en la hoja provista.

ESPECIFICACIÓN DEL MODELO: struct ProductoTienda (A definir por el estudiante) Tipos Primitivos Exclusivos

Cada artículo del inventario de la tienda está modelado por el struct ProductoTienda. El alumno debe declararlo en el código fuente utilizando exclusivamente tipos de datos primitivos (deduciendo el tipo correspondiente para cada campo según su dominio y rango):

Campo Origen Descripción, Tipo y Regla de Cálculo
codigo Entrada (cin) Entero positivo único (> 0). Clave primaria inmutable.
stock Entrada (cin) Cantidad de unidades físicas en depósito (entero, ≥ 0).
categoria Calculado Carácter según existencias: si stock < 20 → 'B' (Bajo); si stock ≤ 50 → 'M' (Medio); caso contrario → 'A' (Alto).
precioBase Entrada (cin) Real con decimales (tipo double, > 0.0). Precio base mayorista del artículo.
valorUnitario Calculado Real con decimales (tipo double): si es 'B' aplica +20% (precioBase * 1.20); si es 'M' aplica +15% (precioBase * 1.15); si es 'A' aplica +10% (precioBase * 1.10).
valorStock Calculado Real con decimales (tipo double): valorStock = valorUnitario * stock. Valuación total del inventario.
Orden Obligatorio de Miembros en el Struct: Declare los campos del struct respetando estrictamente el mismo orden en que aparecen en la tabla. Esto es indispensable para que la inicialización por lista de llaves { ... } del arreglo precargado provista en main() compile sin errores de tipos ni desfasaje de columnas.

2. Alta / Inserción en Posición (Right-Shift)
20%
Alta con Unicidad de Clave
Control de capacidad (tam < CAPACIDAD), validación de posición (0..tam), verificación de no-duplicado reutilizando buscarPorCodigo, desplazamiento Right-Shift y tam++.
  • Firma: bool insertarProducto(ProductoTienda arr[], int &tam, int capacidad, int pos, const ProductoTienda &nuevo) (recibe nuevo con los derivados calculados previamente en el switch).
  • Validaciones: Rechazar (false) si tam >= capacidad, si pos < 0 o pos > tam, o si el código ya existe llamando a buscarPorCodigo.
  • Proceso: Desplazar celdas a la derecha (Right-Shift) desde tam hasta pos + 1, insertar nuevo en arr[pos] e incrementar tam++.
3. Modificación in-place (PK Inmutable)
15%
Modificación con PK Inmutable
Reutilización modular de buscarPorCodigo, actualización in-place sobre arr[pos] y preservación estricta de codigo sin alterar.
  • Firma: bool modificarProducto(ProductoTienda arr[], int tam, const ProductoTienda &actualizado).
  • Proceso: Ubicar el índice mediante buscarPorCodigo. Si existe, actualizar in-place en arr[pos] los atributos stock, categoria, precioBase, valorUnitario y valorStock (ya recalculados al leer en el switch o recalculándolos dentro de la función según las reglas de la tabla), preservando intacto codigo.
  • Retorno: true si se modificó con éxito; false si el código no existe.
4. Burbuja Mejorada e Intercambio de Estructuras
30%
Intercambio Completo de Estructuras
Burbuja Mejorada con bandera huboIntercambio comparando precioBase e invocando intercambiar(ProductoTienda &a, ProductoTienda &b).
  • Firmas: void intercambiar(ProductoTienda &a, ProductoTienda &b) y void ordenarPorPrecioBaseBurbujaAsc(ProductoTienda arr[], int tam).
  • Proceso: Ordenar en forma ASCENDENTE por precioBase con Burbuja Mejorada y corte anticipado por bandera (huboIntercambio), permutando estructuras completas mediante intercambiar(arr[j], arr[j + 1]).
5. Instancia Escrita: Traza de Ordenamiento
25%
Traza Manual en Hoja Impresa
Resolución paso a paso en hoja de examen indicando comparaciones, swaps y prefijo consolidado.
  • Consigna: En la hoja impresa A4, aplique Selección Directa (Selection Sort) para ordenar en forma ASCENDENTE el vector V = [45, 11, 72, 28, 6].
  • Detalle requerido: Detallar en cada una de las 4 pasadas: subarreglo analizado, posición y valor del mínimo detectado, swap efectuado y estado resultante del vector.

int buscarPorCodigo(const ProductoTienda arr[], int tam, int codigoBuscado) {
    for (int i = 0; i < tam; ++i) {
        if (arr[i].codigo == codigoBuscado) {
            return i;
        }
    }
    return -1;
}

bool darDeBajaProducto(ProductoTienda arr[], int &tam, int codigoABorrar) {
    int pos = buscarPorCodigo(arr, tam, codigoABorrar);
    if (pos == -1) return false;
    for (int k = pos; k < tam - 1; ++k) {
        arr[k] = arr[k + 1];
    }
    tam--;
    return true;
}

double calcularPromedioValorUnitario(const ProductoTienda arr[], int tam) {
    if (tam <= 0) return 0.0;
    double suma = 0.0;
    for (int i = 0; i < tam; ++i) {
        suma += arr[i].valorUnitario;
    }
    return suma / tam;
}
