Reglas Comunes y Organización de la Entrega

Archivos Independientes: Si recupera ambos módulos, cree un archivo .cpp distinto por cada módulo (por ejemplo, m3_apellido.cpp y m4_apellido.cpp) para compilar y entregar sin sobreescribir trabajo.
Contratos de C++ Estrictos: No utilice variables globales mutables, std::vector ni asistentes externos/IA. Respete los prototipos, uso de const y referencias pedidos en cada enunciado.
Gestión de Tiempo (Ambos Módulos): Verifique en cada portal la asignación de tema con el docente, compile de forma incremental tras cada función y reserve tiempo al final para la instancia escrita del Módulo 4.
