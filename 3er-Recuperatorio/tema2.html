Contexto Operativo del Sistema

En el complejo eólico Parque Eólico Rawson (Chubut) se supervisa la potencia media diaria (kW) entregada por hasta 15 aerogeneradores utilizando un arreglo unidimensional compacto float potencias[CAPACIDAD]. La plantilla modular provista al pie ya incluye el main() completo con el switch enlazado; implemente únicamente las 5 funciones algorítmicas solicitadas.

Arquitectura de Software: Código Base y Reutilización Modular

La estructura completa de main() (con los case 1..5 del switch ya enlazados), las constantes y el módulo de menú (MostrarMenu) están provistos en la plantilla inferior. El estudiante debe implementar únicamente las 5 funciones algorítmicas puras. La función DarDeBajaAerogenerador debe reutilizar BuscarPotencia para evitar duplicar lógica. Pase el cursor o enfoque cada porcentaje para ver su rúbrica.

1. Opción 1: Registro Controlado de Aerogenerador

Bloque 1 — Carga y Límites (25%)
Bloqueo si tam >= capacidad, validación estricta con while en [50.0, 600.0] e incremento por referencia int &tam.
  • Función: RegistrarAerogenerador(float arr[], int &tam, int capacidad).
  • Validaciones: Verificar cupo disponible (tam < capacidad) y validar la lectura con while entre 50.0 y 600.0 kW antes de insertar en arr[tam] e incrementar tam++.

2. Opción 2: Listado con Filtro Estricto por Umbral

Bloque 2 — Recorrido y Umbral (20%)
Calificador const float arr[], protección tam == 0, filtro estricto > 350.0 sin incluir el borde y conteo total.
  • Función: ListarAerogeneradores(const float arr[], int tam, float umbralOptimo).
  • Proceso: Proteger tam == 0, mostrar cada posición con 2 decimales, etiquetar [RENDIMIENTO OPTIMO] si supera estrictamente 350.0 kW e informar el total.

3. Opción 3: Búsqueda Secuencial en Arreglo

Bloque 3 — Búsqueda Secuencial (15%)
Calificador const float arr[], salida temprana y retorno del índice de primera ocurrencia o -1.
  • Función: int BuscarPotencia(const float arr[], int tam, float valorBuscado).
  • Proceso: Retornar el índice 0..tam-1 de la primera ocurrencia exacta con salida temprana, o -1 si no existe.

4. Opción 4: Baja Física con Compactación Shift-Left

Bloque 4 — Compactación Shift-Left (25%)
Localizar con BuscarPotencia, desplazar for (int i = pos; i < tam - 1; i++) arr[i] = arr[i + 1]; y decrementar tam--.
  • Función: DarDeBajaAerogenerador(float arr[], int &tam).
  • Proceso: Proteger tam == 0, solicitar potencia, localizar reutilizando BuscarPotencia, desplazar las celdas posteriores a la izquierda (Shift-Left) y decrementar tam-- para liberar el cupo.

5. Opción 5: Estadísticas Seguras (Promedio y Mínimo)

Bloque 5 — Estadísticas (15%)
const float arr[], guarda tam == 0, promedio general y potencia MÍNIMA con su posición [posMin].
  • Función: CalcularEstadisticas(const float arr[], int tam).
  • Proceso: Validar tam == 0 sin dividir por cero; calcular e informar la potencia promedio y la potencia mínima junto con su posición en el arreglo.

CÓDIGO BASE C++ (ARREGLO UNIDIMENSIONAL) Plantilla Modular

Inicie su desarrollo copiando la siguiente plantilla oficial con las constantes del dominio, la estructura modular, prototipos y menú interactivo pre-implementado:

codigo_base_tema2.cpp
#include <iostream>
#include <iomanip>

using namespace std;

// =========================================================================
// CONSTANTES DEL DOMINIO (Tema 2: Parque Eólico Rawson)
// =========================================================================
const int CAPACIDAD = 15;
const float MIN_POTENCIA = 50.0f;
const float MAX_POTENCIA = 600.0f;
const float UMBRAL_RENDIMIENTO_OPTIMO = 350.0f;

// =========================================================================
// PROTOTIPOS DE FUNCIONES (5 Funciones a Implementar por el Estudiante)
// =========================================================================
void MostrarMenu(int &opc); // Pre-implementado al pie
void RegistrarAerogenerador(float arr[], int &tam, int capacidad);
void ListarAerogeneradores(const float arr[], int tam, float umbralOptimo);
int  BuscarPotencia(const float arr[], int tam, float valorBuscado);
void DarDeBajaAerogenerador(float arr[], int &tam);
void CalcularEstadisticas(const float arr[], int tam);

int main() {
    float potencias[CAPACIDAD];
    int tam = 0;
    int opc = -1;

    cout << fixed << setprecision(2);

    do {
        MostrarMenu(opc);

        switch (opc) {
            case 1:
                RegistrarAerogenerador(potencias, tam, CAPACIDAD);
                break;
            case 2:
                ListarAerogeneradores(potencias, tam, UMBRAL_RENDIMIENTO_OPTIMO);
                break;
            case 3:
                if (tam == 0) {
                    cout << "\nNo hay aerogeneradores registrados en el sistema.\n";
                } else {
                    float buscado;
                    cout << "\nIngrese potencia a buscar (kW): ";
                    cin >> buscado;
                    int pos = BuscarPotencia(potencias, tam, buscado);
                    if (pos != -1) {
                        cout << "Potencia encontrada en la posicion [" << pos << "].\n";
                    } else {
                        cout << "Potencia no encontrada en el arreglo.\n";
                    }
                }
                break;
            case 4:
                DarDeBajaAerogenerador(potencias, tam);
                break;
            case 5:
                CalcularEstadisticas(potencias, tam);
                break;
            case 0:
                cout << "\nFinalizando sistema de monitoreo Rawson...\n";
                break;
            default:
                cout << "\nOpcion invalida. Intente nuevamente.\n";
                break;
        }
    } while (opc != 0);

    return 0;
}

// =========================================================================
// ESPACIO PARA DESARROLLO DE FUNCIONES POR PARTE DEL ESTUDIANTE
// (Implemente aqui las 5 funciones solicitadas en la consigna)
// =========================================================================

// =========================================================================
// MODULO DE PRESENTACION PRE-IMPLEMENTADO
// =========================================================================

void MostrarMenu(int &opc) {
    cout << "\n=== PARQUE EOLICO RAWSON - GESTION DE AEROGENERADORES ===\n";
    cout << "1. Registrar potencia media diaria (kW)\n";
    cout << "2. Listar aerogeneradores y verificar Rendimiento Optimo\n";
    cout << "3. Buscar potencia registrada\n";
    cout << "4. Dar de baja aerogenerador (Compactacion Shift-Left)\n";
    cout << "5. Calcular estadisticas (Promedio y Minimo)\n";
    cout << "0. Salir\n";
    cout << "Ingrese una opcion: ";
    cin >> opc;
}

CONDICIONES FORMALES DE DESARROLLO Y EVALUACIÓN

  • Modalidad con Plantilla Modular Provista: No existe prueba de escritorio manual; la plantilla base provee constantes, main() con el switch enlazado y MostrarMenu. El estudiante debe implementar exclusivamente las 5 funciones algorítmicas solicitadas.
  • Entorno de Desarrollo: El código debe compilar sin errores bajo estándar C++11/C++17 (Code::Blocks, VS Code, MinGW/GCC).
  • Estructura de Datos Exclusiva: Arreglo unidimensional de tipo float y variable entera lógica tam declarados localmente en main(). Prohibido std::vector, ordenamiento, vectores paralelos y struct.
  • Integridad de Memoria: El respeto por const en funciones de lectura y paso de tam por referencia solo en alta y baja forma parte directa de la rúbrica (penalización directa del 10% en caso de incumplimiento).
  • Aprobación: Calificación mínima neta del 60% una vez aplicadas eventuales penalizaciones directas.
