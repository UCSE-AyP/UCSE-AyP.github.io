Instrucciones para el Estudiante

Bienvenido/a al recuperatorio del Módulo 3 (12/11/2026). Antes de comenzar, verifique con el equipo docente el Tema que le corresponde según su asignación en el laboratorio.

Código Base Modular Provisto: En el enunciado encontrará la plantilla base con librerías, constantes, menú MostrarMenu y estructura main() con el switch completo ya enlazado. Deberá implementar únicamente las 5 funciones algorítmicas puras en C++.
Contratos de Memoria Estrictos: Prohibido el uso de variables globales mutables (tam y el arreglo se declaran en main()). Respete const float arr[] para lectura y int &tam para inserción y baja.
Alcance Estricto Módulo 3: Arreglo unidimensional de tipo float con compactación física Shift-Left. Sin vectores paralelos, ordenamiento, std::vector ni struct.
